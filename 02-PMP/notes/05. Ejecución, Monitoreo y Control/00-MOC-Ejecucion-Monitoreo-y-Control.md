## Fórmulas clave del módulo (referencia rápida)

| Fórmula | Nombre | Uso |
|---|---|---|
| SV = EV−PV | Variación de cronograma | ¿Adelantados o atrasados? |
| CV = EV−AC | Variación de costo | ¿Sobre o bajo presupuesto? |
| SPI = EV/PV | Índice de desempeño de cronograma | >1 bueno, <1 malo |
| CPI = EV/AC | Índice de desempeño de costo | >1 bueno, <1 malo |
| EAC = BAC/CPI | Estimado a la conclusión (caso típico) | Proyección de costo final |
| ETC = EAC−AC | Estimado para terminar | Lo que falta por gastar |
| VAC = BAC−EAC | Variación a la conclusión | Sobre/bajo presupuesto al cierre |
| TCPI = (BAC−EV)/(BAC−AC) | Índice de desempeño por completar (vs BAC) | Eficiencia requerida para cerrar en presupuesto original |
| TCPI = (BAC−EV)/(EAC−AC) | Índice de desempeño por completar (vs EAC) | Eficiencia requerida dado el nuevo pronóstico |

> Estas mismas fórmulas ya aparecieron en [[L5 - Control de costos y valor ganado|M03-L5]] — este módulo las profundiza con más escenarios de pronóstico y las conecta con MS Project.
