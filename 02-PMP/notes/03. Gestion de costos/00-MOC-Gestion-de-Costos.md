## Fórmulas clave del módulo (referencia rápida)

| Fórmula | Nombre | Uso |
|---|---|---|
| Ce = (O+4M+P)/6 | Estimado PERT | Estimación de costo esperado |
| σ = (P−O)/6 | Desviación estándar | Análisis de riesgo del estimado |
| CV = EV−AC | Variación de costo | ¿Vamos sobre o bajo presupuesto? |
| CPI = EV/AC | Índice de desempeño de costo | >1 bueno, <1 malo |
| SV = EV−PV | Variación de cronograma | ¿Vamos adelantados o atrasados? |
| SPI = EV/PV | Índice de desempeño de cronograma | >1 bueno, <1 malo |
| EAC = BAC/CPI | Estimado a la conclusión | Proyección de costo final |
| TCPI = (BAC−EV)/(BAC−AC) | Índice de desempeño por completar | Eficiencia requerida para cerrar en presupuesto |
