Respuesta

Definición

Escalar

Si la amenaza está fuera del alcance del proyecto o excede la autoridad del equipo, la amenaza se escala a
nivel Patrocinador, Programa o Portafolio.

Evitar

Aplica para amenazas de alta probabilidad de ocurrencia y con un impacto negativo alto, el objetivo es
eliminar la amenaza cambiando el o los objetivos del proyecto amenazados con lo cual el impacto se
“aísla” del objetivo general del proyecto.

Transferir

Implica trasladar la responsabilidad de la amenaza a un tercero para que gestione el riesgo y soporte el
impacto en el caso de materializarse, puede implicar el pago de una prima de riesgos o contratar a un
proveedor.

Mitigar

Implica tomar medidas para reducir la probabilidad de ocurrencia y/o el impacto de una amenaza,
cuando no es posible reducir la probabilidad, la respuesta se enfoca en reducir el impacto focalizando
esfuerzos en los factores que impulsan la severidad.

Aceptar

Implica el reconocimiento de una amenaza, pero no se toman acciones inmediatas o proactivas debido a
que la amenaza es de baja prioridad. Se tienen dos enfoques:
• Aceptación Activa: implica en establecer una reserva para contingencias como parte del presupuesto del
proyecto para gestionar la amenaza en el caso de presentarse.
• Aceptación pasiva: Implica no ejecutar acciones proactivas, se basa en una revisión periódica de la
amenaza para asegurar que no se incremente la severidad.

Gestión de riesgos como estrategia para lidiar con la incertidumbre en los proyectos

Todo proyecto está expuesto a diferentes niveles de
incertidumbre, ¿cómo lidiar con ello de una manera efectiva?,
la gestión de riesgos proporciona técnicas y herramientas para
enfrentar la incertidumbre incluso bajo un enfoque adaptativo
alineando las acciones a la generación de valor de manera
progresiva.

A través de este curso hemos analizado las diferencias entre
enfoques predictivos (waterfall) y adaptativos (ágiles),
comprendimos que la incertidumbre representa amenazas y
también oportunidades, comprendimos que relevante estudiar
las características de los riesgos para determinar la respuesta
más adecuada.

Al realizar la evaluación de posible materialización
(proximidad) y de impacto contamos con un mecanismo de
priorización para enfocar un plan de mitigación adecuado el
cual está intrínsecamente relacionado con aplicar el análisis de
impacto financiero (cuantitativo) para contar con un fondo de
contingencia en el presupuesto del proyecto para financiar el
plan de mitigación de riesgos.
