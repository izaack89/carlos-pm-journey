## 📐 Estructura estándar de cada certificación

```
NN-SIGLA/
├── Index-SIGLA.md      ← índice del curso: módulos, material, trazabilidad
├── documentation/      ← PDFs/videos oficiales del curso, por módulo
├── notes/              ← notas de estudio .md, por módulo
└── specs/              ← proyecto aplicado (PIDA) y sus entregables
    └── entregables/    ← semana-N/ · historico/ · documentos vivos
```

## 🚀 Cómo agregar una certificación nueva

1. Crea la carpeta `NN-SIGLA/` (siguiente número disponible).
2. Copia [[99-Templates/Template-Certificacion|Template-Certificacion]] como `NN-SIGLA/Index-SIGLA.md` y llénalo.
3. Coloca el material del primer módulo en `NN-SIGLA/documentation/01. <Nombre>/`.
4. Agrega la fila en la tabla de arriba.
